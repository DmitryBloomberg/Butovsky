# Butovsky VPN

Одностраничный сайт Butovsky VPN на React с production-сборкой Create React App и небольшим HTTP-сервером на встроенных модулях Node.js.

## Запуск

На сервере нужны Node.js и npm. Из корня репозитория запустите:

    bash start.sh

Скрипт установит зависимости по lock-файлу, соберёт сайт в web/v1/build и запустит server.js. Адрес сайта и локальный URL появятся в терминале. Сервер слушает 0.0.0.0 и по умолчанию использует порт 3000.

Можно задать порт и публичный адрес заранее:

    PORT=8080 SITE_URL=https://vpn.example.com bash start.sh

Если сайт работает за reverse proxy или доменом, укажите публичный адрес в SITE_URL, а сам proxy настройте на выбранный порт.

Сайт информационный: регистрации и встроенной оплаты нет. Кнопки тарифов выбирают вариант; для оформления нужно связаться с поддержкой.
